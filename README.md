# JobMatch — умный поиск работы

> **Что это?** Система, которая сама собирает вакансии с HeadHunter, оценивает их под твои критерии и показывает в удобном интерфейсе. Не нужно вручную перебирать сотни вакансий.

---

## Быстрый старт

### 1. Запусти Web UI

```bash
.venv\Scripts\activate   # если не активировано
python start_webui.py
```

Открой в браузере: **http://127.0.0.1:8100**

### 2. Заполни профиль

Перейди на страницу [Профиль](http://127.0.0.1:8100/profile):
- Укажи ожидаемую зарплату
- Настрой фильтры поиска (регионы, должности, ключевые слова)
- Сохрани

### 3. Настрой матрицу оценок

Перейди на страницу [Матрица](http://127.0.0.1:8100/matrix):
- 7 групп критериев (роль, условия, финансы, компания, карьера, технологии, культура)
- У каждой группы и критерия есть **вес** — насколько это важно для тебя
- Чем выше вес — тем сильнее критерий влияет на итоговый Score
- Меняй веса как хочешь

### 4. Смотри вакансии

Перейди на страницу [Вакансии](http://127.0.0.1:8100/vacancies):
- Таблица со Score и категорией (A / Б / В / мимо)
- Фильтр по категории
- Пока вакансий нет — нужно получить HH API токен

---

## Как получить HH API токен

Чтобы JobMatch мог искать вакансии, нужен токен HeadHunter:

1. Зайди на https://dev.hh.ru/
2. Нажми «Зарегистрировать приложение»
3. Название: `JobMatch`, тип: публичное
4. Redirect URI: `https://localhost/`
5. После регистрации получишь `Client ID`
6. Открой ссылку:
   ```
   https://hh.ru/oauth/authorize?response_type=token&client_id=ТВОЙ_CLIENT_ID
   ```
7. Подтверди — токен появится в адресной строке после `access_token=`

Создай файл `.env` в корне проекта и вставь токен:
```
HH_ACCESS_TOKEN=твой_токен_сюда
```

## Матрица оценки — как это работает

Вакансия получает **Score от 1 до 10** по 7 группам критериев:

| Группа | Оценивает |
|--------|-----------|
| Роль и содержание | PM/PO гибрид? Enterprise? Продукт? |
| Условия работы | Удалёнка? Гибрид? Командировки? |
| Финансы | ЗП от 250k? Вилка указана? IT-аккредитация? |
| Компания | Рейтинг HH, отзывы, стабильность |
| Карьера | Рост, обучение, трек до PPM/CPO |
| Технологии | AI/ML, BI/DWH, современный стек |
| Культура | Agile, прозрачность, аутстафф? |

**Score = средневзвешенное по всем группам**

Категории:
- **A (8.5-10)** — идеально
- **Б (7.0-8.4)** — хорошо
- **В (6.0-6.9)** — компромисс
- **< 6.0** — мимо
