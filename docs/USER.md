# ValueHunt — User Guide

## Что это?

ValueHunt — система умного поиска работы. Она автоматически собирает вакансии с HeadHunter, оценивает их по твоей персональной матрице критериев и присылает уведомления в Telegram.

## Быстрый старт

### 1. Получить HH API токен

1. Перейди на https://dev.hh.ru/
2. Нажми «Зарегистрировать приложение»
3. Укажи название: `ValueHunt`
4. Тип: `Приложение будет использовать API для авторизации по протоколу OAuth` (можно и публичное)
5. Redirect URI: `https://localhost/`
6. После регистрации ты получишь `Client ID` и `Client Secret`

**Получение Access Token (простой способ):**
- Используй OAuth implicit flow или Client Credentials
- Или сформируй ссылку:
  ```
  https://hh.ru/oauth/authorize?response_type=token&client_id=ТВОЙ_CLIENT_ID
  ```
- Перейди по ней, подтверди — токен появится в URL после `access_token=` (в адресной строке браузера)

**Сохрани токен:**
Создай файл `.env` в корне проекта:
```
HH_ACCESS_TOKEN=твой_токен_здесь
```

### 2. Установка

```bash
# Установи Python 3.12+ с python.org
# Открой терминал (PowerShell) в папке проекта

python -m venv .venv
.venv\Scripts\activate     # Windows
pip install -r requirements.txt
playwright install chromium
```

### 3. Настройка профиля

**Через Web UI (рекомендуется):**
Запусти Web-интерфейс, открой в браузере и заполни профиль через формы.

**Или вручную:**
Отредактируй `config/profile.json`:
- Укажи `hh_resume_id` — ID твоего резюме на HH
- Настрой фильтры поиска под себя

### 4. Запуск Web UI

```bash
# Активируй окружение (если ещё не)
.venv\Scripts\activate

# Запусти Web UI
python start_webui.py

# Открой в браузере:
# → http://127.0.0.1:8100
```

**Страницы Web UI:**
| Адрес | Что там |
|-------|---------|
| `/` | Дашборд — статистика, кнопка сканирования |
| `/profile` | Анкета — имя, ЗП, фильтры поиска, интеграции |
| `/matrix` | Матрица — веса групп и критериев |
| `/vacancies` | Таблица вакансий со Score и статусом |

## Telegram Bot (скоро)

После настройки Telegram-бота ты сможешь:

- `/today` — новые вакансии за сегодня с Score
- `/stats` — статистика за неделю
- `/top` — топ-5 вакансий по Score
- `/companies` — статусы по целевым компаниям
- `/remind` — напоминания

## Как это работает

```
1. Web UI → ты заполняешь профиль и матрицу оценок (через браузер)
2. HH API → сканер собирает новые вакансии по твоим фильтрам
3. Scorer → оценивает каждую вакансию по матрице (7 групп критериев)
4. Web UI → ты видишь вакансии со Score, сортируешь, выбираешь
5. Telegram → уведомление (скоро): "Найдено 3 новых вакансии"
```

## Матрица оценки

Вакансия оценивается по 7 группам критериев:

| Группа | Вес | Что оценивает |
|--------|:---:|---------------|
| Роль и содержание | 10 | PM/PO гибрид, Enterprise, продукт |
| Условия работы | 10 | Удалёнка, гибрид, командировки |
| Финансы | 9 | ЗП от 250k, прозрачность |
| Компания | 8 | Репутация, отзывы |
| Карьера | 8 | Рост, обучение |
| Технологии | 7 | AI/ML, BI, современный стек |
| Культура | 7 | Agile, прозрачность |

Итоговый Score от 1 до 10, категории:
- **A (8.5-10)** — идеальное попадание
- **Б (7.0-8.4)** — сильное совпадение
- **В (6.0-6.9)** — компромисс
- **< 6.0** — пропустить
