# ValueHunt — User Guide

## Что это?

ValueHunt — система поиска работы с умным скорингом. Она собирает вакансии с HeadHunter, оценивает по твоей личной матрице критериев и показывает на дашборде.

## Быстрый старт

### Вариант 1 — Готовая сборка (рекомендуется)

1. Скачай последний релиз: `ValueHunt.zip`
2. Распакуй в любую папку (например `C:\Tools\ValueHunt`)
3. Запусти `ValueHunt.exe`
4. Открой браузер: [http://127.0.0.1:8100](http://127.0.0.1:8100)

Всё. Сервер работает локально, данные хранятся в папке рядом с exe.

**Обновление:** скачай новую версию, распакуй поверх старой — конфиги и БД сохранятся.

### Вариант 2 — Из исходников (Python)

```powershell
git clone https://github.com/outmilker/ValueHunt
cd ValueHunt
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
playwright install chromium
start_webui.py
```

## Страницы

### Дашборд (`/`)

Главный экран. Показывает:

- **Сводка**: всего вакансий, компаний, средний балл, S+A категории
- **Категории скоринга**: кольцевая диаграмма — распределение по S/A/B/C/Пропустить
- **Воронка отклика**: сколько вакансий на каждом этапе (Новые → Отклик → Созвон → Принято/Отказ/Архив)
- **Динамика по дате публикации**: столбцы по дням. Переключай: 7/14/30 дней / всё время / календарь. Выбирай разрез: «Всего», «По категориям», «По статусам»
- **Новые за период**: переключай день/неделя/месяц/всё время — счётчики и столбцы по категориям
- **Фильтр по профилю**: данные пересчитываются для выбранного профиля

### Профили (`/profile`)

Управление несколькими профилями поиска. У каждого профиля:

- **Название** — например «PM», «PO», «Enterprise»
- **Резюме** — ФИО, должность, ЗП, навыки, роли (HH)
- **Настройки поиска** — текст, регион, ЗП, период, опыт, роли

Кнопки:
- **+ Новый** — создать профиль (введи название)
- **Удалить** — удалить профиль и его настройки
- **Загрузить и распарсить** — загрузи TXT-экспорт резюме с HH, поля заполнятся
- **Копировать из резюме** — скопировать настройки поиска из данных резюме
- **Сохранить профиль** — сохранить все изменения

### Матрица (`/matrix`)

Редактор весов скоринга. Группы критериев, внутри — критерии с весом 1-10.
Скоро: переключение матрицы по профилю.

### Контакты (`/contacts`)

База HR-контактов. Показывает:

- **Таблица контактов**, сгруппированная по приоритету S/A/B/C
- **Фильтры**: по приоритету, по источнику (HH, Telegram, LinkedIn, рекомендация, VK, email)
- **Клик на контакт** — модалка: редактирование контакта + история взаимодействий
- **Просроченные действия** — блок сверху, если есть контакты с `next_action_date` <= сегодня

**В модалке контакта можно:**
- Редактировать: имя, роль, источник, приоритет, Telegram, email, телефон, VK, LinkedIn, заметки
- Просмотреть историю взаимодействий (отклики, созвоны, отказы)
- Добавить новое взаимодействие: тип (первое обращение/напоминание/созвон/собес/тестовое/оффер/отказ), направление (исходящее/входящее), суть, результат, дата следующего действия

**Как контакты появляются:**
- Импорт из `contacts.md` (скрипт `scripts/import_contacts.py`)
- Ручное добавление через кнопку «+ Добавить контакт»
- В будущем — автоматический парсинг из текста вакансии

### Вакансии (`/vacancies`)

Таблица всех найденных вакансий.

Фильтры:
- **Категория**: S / A / B / C / Пропустить
- **Статус**: Новые / Отклик / Созвон / Принято / Отказ / Архив
- **Период**: сутки / неделя / месяц / произвольный (календарь)
- **Сортировка**: Score / дата публикации / дата добавления

Кликни на название вакансии → детальная карточка. Там можно изменить статус.

## Как работает сканер

1. Нажимаешь «Запустить сканирование» на дашборде
2. Система идёт на HH.ru с твоими фильтрами (текст, регион, роли, ЗП)
3. Найденные вакансии оцениваются UES Calculator
4. Каждая вакансия получает Score и категорию (S/A/B/C/Пропустить)
5. Результат сохраняется в БД и отображается на дашборде

Сообщение сканера: «HH.ru показал X вакансий. Добавлено в БД: Y, уже были: Z. Всего в БД: W»

## Профили

С версии 1.12.0 появилась система профилей. Можно создать несколько независимых конфигураций поиска (например, для разных резюме или разных направлений). При сканировании выбери профиль — данные привяжутся к нему. На дашборде можно фильтровать по профилю.

## Категории скоринга

| Категория | Score | Описание |
|-----------|-------|----------|
| S | 8.0+ | Идеально — высший приоритет |
| A | 7.0+ | Отлично — очень хорошее совпадение |
| B | 6.0+ | Хорошо — можно рассматривать |
| C | 5.0+ | Возможно — если нет лучших |
| Пропустить | <5.0 | Не подходит — не трать время |

## Статусы вакансий

| Статус | Что значит |
|--------|-----------|
| new | Только что найдены, действий нет |
| applied | Откликнулся |
| follow_up | Напомнил о себе |
| call | Был созвон/интервью |
| in_progress | Проходишь этапы собесов |
| offer | Получил оффер |
| rejected | Отказ (твой или их) |
| archived | Вакансия закрыта/неактуально |
| closed | Сам отказался |

Статусы меняются **вручную** на странице детальной карточки вакансии.

### Корзина (`/trash`)

Вакансии, которые не подходят, можно отправить в корзину.

**Как удалить:**
- В карточке вакансии → кнопка «🗑 Удалить» → выбрать причину → подтвердить
- Причины: Зарплата ниже ожидаемой / Локация не подходит / Не мой профиль / Дубль вакансии / Нет удалёнки / Другое

**Что происходит:**
- Вакансия пропадает из дашборда, списка вакансий и отчётов
- Остаётся в корзине с причиной и баллом матрицы

**В корзине можно:**
- «↩ Вернуть» — восстановить в статус "Новые"
- «× Удалить навсегда» — безвозвратно удалить из БД

**Счётчик** в боковом меню показывает количество вакансий в корзине.
