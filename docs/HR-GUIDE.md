# ValueHunt — Руководство для HR по работе с базой

> Система учёта контактов, вакансий и взаимодействий в процессе поиска работы.
> Веб-интерфейс: `http://127.0.0.1:8100`

---

## 1. Контакты (страница /contacts)

### Поля в карточке контакта

| Поле | Описание | Обязательно |
|------|----------|-------------|
| **Имя** | ФИО контакта | Да |
| **Роль** | Должность / функция (HR, Recruiter, Hiring Manager...) | Нет |
| **Компания** | Название компании (поиск по мере ввода) | Нет |
| **Источник** | Откуда получен контакт: HH, Telegram, LinkedIn, Рекомендация, VK, Email, Сами вышли на меня, Сетка, Хабр Карьера, Getmatch, AI | Нет |
| **Приоритет** | S — в плане / B — в работе (по умолч.) / C — имею в виду | Нет |
| **Telegram** | @username | Нет |
| **Email** | Адрес эл. почты | Нет |
| **Телефон** | Номер телефона | Нет |
| **Социальные сети** | Динамические ссылки: VK, LinkedIn, Хабр Карьера и т.д. Добавляются кнопкой «+ Добавить ссылку» | Нет |
| **Заметки** | Произвольный текст | Нет |

### Действия

- **➕ Добавить контакт** — кнопка над таблицей
- **Клик по строке** — открыть карточку для редактирования
- **«→ Вакансии»** (рядом с полем Компания) — перейти к вакансиям выбранной компании
- **«📋 Копировать»** (рядом с Telegram, Email, Телефон) — скопировать значение в буфер
- **✕** (в правом краю строки) — удалить контакт

### Приоритет — цветовая маркировка

Цвет приоритета меняется динамически:
- **S/B** — синий, если `next_action_date` не просрочен; **красный**, если просрочен
- **C** — всегда серый

## 2. Взаимодействия (поле в карточке контакта)

Раздел «История взаимодействий» внизу карточки контакта.

### Поля

| Поле | Варианты |
|------|----------|
| **Тип** | Первое обращение, Напоминание, Звонок/Созвон, Собеседование, Тестовое, Оффер, Отказ, Другое |
| **Направление** | Исходящее (мы написали) / Входящее (нам написали) |
| **Суть** | Текстовое описание сути обращения |
| **Результат** | Ожидание / Успешно / Отказ |
| **Следующее действие до** | Дата, до которой нужно выполнить следующее действие |

> **Важно**: если указана `next_action_date` и она <= сегодня — контакт попадает в баннер «Просроченные действия» на главной странице контактов.

## 3. Вакансии (страница /vacancies)

### Статусы вакансий (полный цикл)

| Статус | Значение |
|--------|----------|
| `new` | Новая (ещё не откликались) |
| `applied` | Отклик отправлен |
| `follow_up` | Назначен созвон / напоминание |
| `call` | Перезвон |
| `in_progress` | В работе (прохождение собеседований) |
| `offer` | Получен оффер |
| `rejected` | Отказ |
| `archived` | В архиве |
| `closed` | Закрыта (наниматель закрыл позицию) |

### Категории (оценка вакансии)

| Категория | Значение | Цвет |
|-----------|----------|------|
| S | Идеально | зелёный |
| A | Отлично | синий |
| B | Хорошо | жёлтый |
| C | Возможно | оранжевый |
| REJECT | Пропустить | красный |

### Фильтры

- Профиль (резюме, под которое анализировалась вакансия)
- Категория, статус, период, компания
- Поиск по названию / компании
- Сортировка: Score, дата публикации, дата добавления

### Привязка компании

Вакансии привязываются к компаниям по названию (поле `company`).
Для корректной работы графа связей необходима нормализация: `vacancies.company` → `companies.id`.

## 4. Просроченные действия (баннер на /contacts)

Автоматически показывает контакты, у которых:
- Есть взаимодействие с заполненной `next_action_date`
- `next_action_date` <= сегодня

Клик по имени → открывает карточку контакта для работы.

---

## 5. Резервное копирование (страница /backup)

- **«📦 Создать бэкап»** — копирует БД + экспорт всех таблиц в JSON
- **Экспорт по таблицам**: contacts, companies, vacancies, interactions, profiles
- Бэкапы сохраняются в `data/backups/`

## 6. Техническая структура БД

### contacts

| Колонка | Тип | Назначение |
|---------|-----|------------|
| id | INTEGER PK | |
| company_id | INTEGER → companies.id | Компания |
| name | TEXT | Имя контакта |
| role | TEXT | Должность |
| source | TEXT | Источник |
| priority | TEXT | S/B/C |
| telegram | TEXT | @username |
| email | TEXT | Email |
| phone | TEXT | Телефон |
| vk | TEXT | VK (устаревает, заменён на extra_contacts) |
| linkedin | TEXT | LinkedIn (устаревает) |
| extra_contacts | TEXT (JSON) | Соцсети: `[{"label":"VK","url":"vk.com/..."}]` |
| notes | TEXT | Заметки |
| created_at | TEXT | Дата создания |

### interactions

| Колонка | Тип | Назначение |
|---------|-----|------------|
| id | INTEGER PK | |
| contact_id | → contacts.id | Контакт |
| vacancy_id | → vacancies.id | Вакансия (опционально) |
| type | TEXT | Тип |
| direction | TEXT | inbound/outbound |
| summary | TEXT | Суть |
| outcome | TEXT | pending/positive/negative |
| next_action_date | TEXT | Следующее действие до |
| created_at | TEXT | Дата создания |
