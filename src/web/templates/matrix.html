Матрица оценки UES

Веса сохраняются в matrix.yaml — пересчёт обновит оценки всех загруженных вакансий и будет применяться к новым при импорте. После изменения весов нажми «Сохранить», затем кнопку подтверждения для пересчёта.

Как работает оценка

UES (Unified Evaluation Score) — алгоритмическая система скоринга вакансий. Без LLM, только ключевые слова и правила.

  1. БЛОКИ — красные флаги (гемблинг, не-PM-роль, геймдев). Если сработал → REJECT, score=0, без дальнейшего анализа.
  2. GATE A — жёсткие проходные фильтры: удалёнка / гибрид, зарплата ≥200k, локация Мск/СПб. Если хоть один не пройден → REJECT (с частичным баллом, чтобы видеть насколько близко).
  3. GATE B — проверка архетипа резюме (01 Enterprise PM / 03 Hybrid PM-PO). Если ни один не совпал → REJECT.
  4. Override — если Gate A не пройден, но Gate B пройден, Company≥6.5 и Fit (role+tech+culture)≥6.0 → Gate A принудительно пропускается. Вакансия оценивается полностью, рекомендация apply_terms.
  5. Скоринг (если GATE пройдены) — 7 групп критериев. Каждый критерий имеет вес внутри своей группы и набор ключевых слов из matrix.yaml. Если у критерия нет ключевых слов — оценка = zero_keyword_default из конфига (5.7). Если есть — количество совпадений в описании маппится в балл по match_curve: 0→5.0, 1→8.0, 2+→10.0. Итоговый балл группы = взвешенное среднее критериев (0–10). Итоговый балл вакансии = взвешенное среднее групп.
  6. Автообновление — изменения весов и замена критериев сохраняются сразу в matrix.yaml и применяются к следующему скорингу без перезапуска сервера.

Итоговые категории: S (8.0+) Идеально · A (7.0+) Отлично · B (6.0+) Хорошо · C (5.0+) Возможно · REJECT (<5.0 или не пройдены GATE/БЛОКИ)

Замена критерия

У каждого критерия есть выпадающий список альтернатив. Выбери — и он заменит текущий критерий. Вес останется прежним. Это позволяет перенастраивать матрицу без потери структуры.
Пример: вместо «Удалёнка 100%» можно поставить «Гибрид» или «Офис в доступности» — вес останется 10.
